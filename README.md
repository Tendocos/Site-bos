# 🛡️ Site B.O.S : Brigade des Opérations Spéciales

Documentation de la structure du site **Google Sites** de la Brigade des Opérations Spéciales (B.O.S), une unité de jeu de rôle (RP) de type *Star Wars / Guerres des Clones*.

> 🔗 Site officiel : https://sites.google.com/view/site-bos/accueil
> 👥 Direction B.O.S : **Troxi / Tendo**

---

## 📌 À propos

Le site sert de **centre de ressources interne** pour les membres de la brigade : organisation, règlements, procédures d'interrogatoire, autorisations de protocole, distinctions et effectifs.

Ce dépôt GitHub **ne contient pas le site lui-même** (il est hébergé sur Google Sites). Il sert à **documenter** son organisation et à garder une trace de sa structure.

---

## 🗺️ Structure du site

| Section | Contenu |
|---|---|
| 🌐 **Accueil** | Page de présentation de la B.O.S et de sa direction |
| 📑 **Hiérarchie** | Hiérarchie de la flotte · Hiérarchie B.O.S (en mission) |
| 📄 **Règlements internes** | Un règlement par unité (voir ci-dessous) |
| 🗂️ **Interrogatoires** | Procédures d'interrogatoire par unité |
| 📝 **Autorisations de protocole** | Autorisations par unité (hors B.O.S) |
| 📖 **Accréditations B.O.S** | Accréditations des membres |
| 🎖️ **Médailles B.O.S** | Distinctions et récompenses |
| 📁 **Effectif B.O.S** | Liste des membres |
| 👮 **Qui peut vous ordonner un protocole ?** | Chaîne de commandement pour les ordres |
| 🔱 **Grades de la Direction B.O.S** | Grades du commandement |

### Les unités couvertes

- **B.O.S**: Brigade des Opérations Spéciales
- **B.R.S**: Bureau de Renseignement Sénatorial
- **RC**: Republic Commando
- **Arc Alpha**: Advanced Recon Commandos
- **Clone Force 99**: Bad Batch

Chaque unité dispose de ses pages de **règlement interne**, d'**interrogatoire** et (sauf la B.O.S) d'**autorisation de protocole**.
